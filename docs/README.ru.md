# QuietBar

[![Проверка сборки и пакетов](https://github.com/miha1744/QuietBar/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/miha1744/QuietBar/actions/workflows/ci.yml)

**Спокойная строка меню macOS.**

QuietBar — небольшая нативная утилита для macOS, созданная вокруг фиолетового индикатора демонстрации экрана. В ней есть системный режим скрытия, если нужный API доступен, и экспериментальный способ запуска Jump Desktop Connect для более ранних версий macOS.

[English](../README.md) · [Совместимость и доказательства](compatibility.md) · [Устройство приложения](architecture.md)

Используйте QuietBar на своём Mac, с ведома людей, которые им пользуются. **Скрытие индикатора не останавливает захват экрана или удалённый доступ.**

## Текущее состояние

| Режим | Что известно |
| --- | --- |
| Системный фильтр | Скрытие группы индикаторов наблюдалось на macOS 27.0.1 с Apple Silicon. Используется частный API; обновление macOS может изменить его поведение. |
| Экспериментальный запуск Jump | Реализован для macOS 14 и новее при отсутствии системного API. Реальное подключение Jump, передача изображения, ввод и скрытие индикатора вместе ещё не проверены. |

Приложение собирается для **macOS 14+**, **Apple Silicon и Intel**. Универсальный исполняемый файл не означает, что проверена каждая версия системы и модель Mac. Подробности — в [матрице совместимости](compatibility.md).

Сейчас в QuietBar один переключатель режима. Выбора отдельных приложений или значков нет. Вместе с индикатором системный режим может скрыть AirDrop, «Фокусирование» и «Исполняется» (Now Playing).

## Установка или сборка

Скачайте универсальный DMG из [1.2.0 Preview 1](https://github.com/miha1744/QuietBar/releases/tag/v1.2.0-preview.1), перетащите QuietBar в «Программы», извлеките образ и запустите установленную копию. Это **экспериментальная версия без нотариального заверения Apple**. Для использования готового приложения вводить команды не нужно.

Для сборки из исходников на Mac с установленными Xcode Command Line Tools выполните из папки репозитория:

```sh
./build.sh
```

В `dist/` появятся `QuietBar.app`, универсальный ZIP и DMG. Откройте DMG, перетащите приложение в «Программы», извлеките образ и запустите установленную копию. Скрипт не устанавливает и не запускает приложение. Другие пути и параметры подписи описаны в `./build.sh --help`.

Локальная сборка имеет **ad-hoc подпись без нотариального заверения Apple**. Флаг `--hardened-runtime` включает усиленную среду выполнения, но не заменяет Developer ID и нотариальное заверение. Если macOS блокирует доверенную копию, после попытки запуска может появиться кнопка **«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»**. Она доступна не на каждом Mac. См. [инструкцию Apple](https://support.apple.com/en-us/102445).

## Использование

Интерфейс приложения сейчас на русском языке. Открыть настройки повторно можно через значок QuietBar в строке меню.

**Системный режим:** нажмите **«Скрыть значки»**. Для отмены нажмите **«Показать значки»**. Когда курсор находится возле часов, группа временно возвращается, чтобы можно было открыть Центр уведомлений. Выход из QuietBar освобождает системный фильтр.

**Экспериментальный режим Jump:** подготовка перезапускает пользовательский агент Jump и может прервать подключение. Первый раз проверяйте режим, имея доступ к самому Mac.

1. Установите Jump Desktop Connect в `/Applications`. В его настройках самостоятельно включите **General → Start Jump Desktop when my computer starts**. См. [справочник настроек Jump](https://docs.jumpdesktop.com/connect/settings-reference/).
2. Нажмите **«Подготовить Jump»**. Если нужны разрешения, нажмите **«Настроить разрешения…»** и разрешите Terminal запись экрана и универсальный доступ в штатных настройках macOS. QuietBar открывает Terminal автоматически; вводить команды не требуется. Разрешения самого Jump также должны оставаться включёнными.
3. Вернитесь в QuietBar и повторите подготовку. **«Запуск Jump подготовлен»** означает, что созданный агент остаётся запущенным. Подключитесь заново и отдельно проверьте обновление экрана, мышь, клавиатуру и отсутствие индикатора на этом Mac.
4. Для отмены нажмите **«Вернуть обычный запуск»**. Дождитесь восстановления; при необходимости подключитесь заново.

В экспериментальном режиме Terminal получает широкие разрешения. QuietBar проверяет их до изменения запуска пользовательского агента. Приложение не правит базу разрешений macOS, не отключает SIP и не меняет системный демон Jump. Точная область изменений и ограничения восстановления описаны в [архитектуре](architecture.md).

Для запуска QuietBar при входе оставьте приложение в постоянной папке и включите флажок автозапуска. macOS может запросить подтверждение в разделе **«Основные → Объекты входа»**.

## Дальнейшая работа

Главная задача — проверить настоящий Jump на Mac с включённым SIP, включая повторное подключение и восстановление. Правила для отдельных приложений или системных значков возможны как будущее развитие совместимого нативного API; сейчас их нет. Экспериментальный способ запуска предназначен только для Jump Desktop Connect.
