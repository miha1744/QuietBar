QuietBar 1.2.0 (3)
macOS 14.0 и новее · Apple Silicon и Intel

1. Установка и запуск

Откройте QuietBar-1.2.0-universal.dmg, перетащите QuietBar.app на ссылку
Applications («Программы»), извлеките образ и запустите скопированное
приложение. Можно также распаковать ZIP и перенести приложение в «Программы».
Для установки только своему пользователю подойдет папка «Программы»
в домашней папке. Команды в Терминале вводить не нужно.

Эта сборка имеет локальную ad-hoc подпись, без Developer ID и notarization.
Если macOS блокирует открытие, сначала проверьте источник копии. Если вы
доверяете ей, после попытки запуска откройте «Системные настройки →
Конфиденциальность и безопасность → Все равно открыть» (Open Anyway),
если macOS предлагает эту кнопку. Это не гарантирует открытие на каждом Mac.
Официальная инструкция Apple: https://support.apple.com/102445

На macOS 27 доступен режим «Скрыть значки» через системный API. Нажмите
«Показать значки», чтобы отменить скрытие. Вместе с фиолетовым индикатором
могут скрыться AirDrop, «Фокусирование» и «Исполняется» (Now Playing).

Для автозапуска QuietBar оставьте приложение в постоянной папке и включите
флажок в его настройках. Если macOS требует подтверждения, разрешите QuietBar
в «Системные настройки → Основные → Объекты входа».

2. Подготовка Jump на macOS 14, 15 и 26

Этот режим экспериментальный. Он готовит другой способ запуска агента
Jump Desktop Connect; сообщение «Запуск Jump подготовлен» не означает,
что индикатор уже скрыт или удаленное управление проверено.

1) Установите Jump Desktop Connect в общую папку «Программы» (/Applications).
   Откройте его окно и нажмите
   значок шестеренки (Settings), выберите General и включите флажок
   «Start Jump Desktop when my computer starts».
   Это штатный автозапуск Jump. При выключенном флажке минимизированный
   агент Jump завершает работу, поэтому подготовка не сможет его сохранить.
   Путь подтвержден для установленного Connect 10.15.32 и документацией:
   https://docs.jumpdesktop.com/connect/settings-reference/

2) В QuietBar нажмите «Подготовить Jump». Если нужны разрешения, появится
   кнопка «Настроить разрешения…». Откройте её и в штатных настройках macOS
   разрешите приложению Terminal («Терминал») запись экрана и «Универсальный
   доступ». Раздел записи на новых macOS называется «Запись экрана и
   системного аудио». Если macOS предложит завершить и открыть Terminal
   заново, подтвердите. QuietBar использует Terminal автоматически;
   самостоятельно вводить команды не требуется. Эти разрешения позволяют
   Terminal записывать экран и управлять интерфейсом, поэтому выдавайте их
   только если доверяете этому способу запуска.

3) Вернитесь в QuietBar и повторите «Подготовить Jump». Будет перезапущен агент Jump текущего
   пользователя. Активное подключение может прерваться: подключитесь снова
   и проверьте обновление экрана, движение мыши и ввод текста.
   Разрешения самого Jump также должны оставаться включенными.

4) Для отмены нажмите «Вернуть обычный запуск». При возврате агент Jump
   тоже может перезапуститься, а подключение — потребовать повторного входа.

На время работы обёртки исходный LaunchAgent текущего пользователя
выгружается; при выключении его регистрация восстанавливается. Его plist
сохраняется без изменений. Системная служба Jump и база разрешений macOS
не затрагиваются. Флажок автозапуска Jump пользователь включает
самостоятельно в штатном окне Connect.

3. Совместимость и известные ограничения

• Минимальная версия приложения — macOS 14.0. Исполняемый файл универсальный:
  arm64 и x86_64. Наличие сборки не подтверждает работу на каждом Mac.
• Режим macOS 27 использует частный API; ранее удаление группы индикаторов
  проверялось на macOS 27.0.1 с Apple Silicon. Это не проверка всех версий
  macOS 27 или всех моделей Mac. Обновления системы могут изменить API.
• На macOS 14, 15 и 26 запуск через Terminal проверялся только с собственным
  тестовым потоком ScreenCaptureKit в CI, где SIP был отключен. Это не
  подтверждение работы Jump Desktop или обычного Mac с включенным SIP.
  Реальное удаленное изображение, мышь и клавиатуру Jump в этом режиме
  еще предстоит проверить; отсутствие значка само по себе недостаточно.
• QuietBar не отключает SIP и не рисует полосу или накладку поверх строки
  меню. Скрытие индикатора не останавливает запись экрана или удаленный доступ.
• Ad-hoc подпись не обходит Gatekeeper. Надежный перенос без предупреждения
  о непроверенном разработчике требует Developer ID и нотариального
  заверения Apple; эта копия их не имеет.
• Используемый частный API не предназначен для Mac App Store.
