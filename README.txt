QuietBar 1.3.0 (4) — экспериментальная версия
macOS 14.0 и новее · Apple Silicon и Intel

Установка

Откройте QuietBar-1.3.0-universal.dmg, перетащите QuietBar.app в Applications
(«Программы»), извлеките образ и запустите установленную копию.
Вводить команды в Терминале не нужно.

Сборка имеет ad-hoc подпись, без Developer ID и нотариального заверения Apple.
Если macOS блокирует доверенную копию, после попытки запуска используйте
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»,
если macOS предлагает эту кнопку. Открытие не гарантировано на каждом Mac.
Инструкция Apple: https://support.apple.com/102445

macOS 14, 15 и 26: выбрать приложение

1. Завершите приложение, которое захватывает или передаёт экран. Сохраните документы.
2. Нажмите «Выбрать приложение…» и укажите его .app в Finder.
3. Нажмите «Запустить через QuietBar». При необходимости откройте настройку
   разрешений и разрешите Apple Terminal запись экрана. Разрешения выбранного
   приложения также должны быть настроены. Для удалённого управления могут
   понадобиться дополнительные штатные разрешения самого приложения.
4. Повторите запуск, включите запись или подключитесь к этому Mac.
   Проверьте обновление изображения, управление и отсутствие индикатора.
5. «Завершить запуск» просит выбранное приложение закрыться обычным способом.
   При запросе сохранения документа завершите его вручную и нажмите
   «Проверить завершение». Следующий обычный запуск выполняется через Finder.

Terminal открывается автоматически и запускает внутреннюю обёртку.
Команды самостоятельно вводить не требуется. Разрешение записи экрана
действует на Terminal, поэтому выдавайте его только доверенной программе.
QuietBar не запускает выбранное приложение автоматически при входе в систему.

Это общий запускатель .app, а не подтверждённая поддержка любой программы.
Он не переключает уже работающий захват и не управляет независимыми службами.
Если захватывает отдельный LaunchAgent, XPC-процесс, root-служба или другой
экземпляр, способ может не скрыть индикатор. Состояние «Приложение запущено»
означает только, что выбранный процесс работает. Для каждого приложения
нужно отдельно проверить захват, управление и индикатор на нужном Mac.

macOS 27: системный фильтр

При наличии нужного частного API QuietBar выбирает общий системный фильтр.
Нажмите «Скрыть значки» / «Показать значки». Вместе с индикатором могут
скрыться AirDrop, «Фокусирование» и «Исполняется». У часов значки временно
возвращаются. Выход из QuietBar снимает фильтр.

Проверки и ограничения

• Минимальная версия 14.0 и универсальный исполняемый файл не означают,
  что проверены все версии macOS и приложения. Точная матрица и результаты:
  https://github.com/miha1744/QuietBar/blob/main/docs/compatibility.md
• Предыдущие эксперименты ScreenCaptureKit на macOS 14, 15 и 26 выполнялись
  в CI с отключённым SIP. Это не проверка произвольных приложений на обычном Mac.
• QuietBar не отключает SIP, не редактирует базу разрешений macOS,
  не перекрывает строку меню полосой и не меняет подпись выбранного приложения.
• Скрытие индикатора не останавливает запись или удалённый доступ.
• Для надёжной установки без предупреждений Gatekeeper нужны Developer ID
  и нотариальное заверение Apple; эта копия их не имеет.
